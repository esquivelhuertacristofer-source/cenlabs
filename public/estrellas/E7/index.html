Cómo se evalúa y qué no garantiza

Simulación educativa. El horno y sus parámetros son ilustrativos (diseño CEN), no los de un equipo concreto. Nada se envía a internet. Tu trabajo, el registro de intentos (cargas de la variante, entregas y cierre) y los bloqueos se guardan en este navegador por identificador y se recuperan al recargar; el expediente exportado lleva ese registro y una huella SHA-256 (detecta daños y ediciones casuales; no es una firma, porque quien edite el archivo puede recalcularla).

El identificador se normaliza (sin espacios ni acentos y en mayúsculas): «a-123», «a 123» y «A123» son el mismo alumno (solo cuentan letras y dígitos), con el mismo horno y el mismo registro. Si abres la práctica en varias pestañas, el registro es uno solo: una entrega o un cierre en una pestaña bloquea las demás.

Límite declarado: un paquete local no puede garantizar la entrega única, porque el almacenamiento del navegador se puede borrar; esa garantía requiere la plataforma con servidor. El registro y la huella hacen visible un reintento, pero no lo impiden.

Este navegador no permite guardar datos (navegación privada o almacenamiento bloqueado): el registro de intentos no se conservará al recargar y el AT no dará cifras. Usa una ventana normal.
Este navegador no ofrece WebGL: no se puede dibujar el horno en 3D. La práctica sigue funcionando con el controlador, las tendencias y las tablas.

Leer el encargo completo

Eres el ingeniero de control de un taller de tratamientos térmicos. Se sustituyó el controlador de un horno de revenido y quedó con los valores de fábrica. Con ellos el horno no sobrepasa la consigna y aguanta la apertura de la puerta, pero el lazo queda con poco margen de estabilidad (un Ms mayor que el que admite el criterio): responde con oscilaciones poco amortiguadas y, si el termopar tiene ruido, la salida se mueve con violencia. Compruébalo en el paso 0; después identifica el proceso, sintoniza con varios métodos, compáralos de forma justa y deja el controlador configurado.
