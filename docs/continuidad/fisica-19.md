## Implementación
Una onda recorre una conducción; relacionar cierre, propagación y sobrepresión.

Reto: Estima la sobrepresión causada por el cierre de una válvula y distingue cierre rápido de lento.

Modelo: ρ=998 kg/m³, a=1200 m/s, L=80 m. tc=2L/a. ΔP=ρaU min(1,tc/tcierre). Para cierre lento es la aproximación lineal de Michaud; para rápido, Joukowsky.

Límites: Tubería uniforme y cierre idealizado. La escena muestra frentes característicos; no resuelve MOC completo, cavitación, pérdidas ni interacciones de una red.

Escala: Frente de presión 1D · onda ralentizada

Formato: MissionBriefing inicial, Piloto/Bitácora React nativos, adquisición de 6 s, validación con registro vigente, quiz oficial y descarga. Cambiar ajustes borra evidencia y aceptación; restaurarlos no recupera el ensayo.
